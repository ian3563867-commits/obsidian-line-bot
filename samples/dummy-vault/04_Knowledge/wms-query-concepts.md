# WMS 通用查詢概念

倉儲管理系統（Warehouse Management System）查詢通常會牽涉到以下實體：

- **儲位**：實體存放位置，常用三段碼（區/列/層）
- **棧板**：可移動的承載單位，貼條碼/RFID
- **入庫單 / 出庫單**：交易主檔，含表頭與明細
- **批號 / 序號**：可追溯性的最小單位
- **盤點任務**：定期循環盤、抽盤、全盤

## 常見問題分類

1. **存量查詢**：某料號在哪些儲位、各多少
2. **異動追溯**：某棧板/批號的進出歷程
3. **任務狀態**：揀貨、補貨、上架、盤點的進度
4. **異常追查**：揀貨短缺、儲位差異、系統與實體不符

## Retrieval 設計建議

對 WMS 查詢，先依關鍵字判斷分類，再走對應的 SQL 模板。模板層級的 deterministic pre-check 比 embedding similarity 穩定許多。
